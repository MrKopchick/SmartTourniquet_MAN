```
man/
├── README.md        цей файл: структура роботи та чек-лист
├── figures/         схеми, фото прототипу, графіки (PNG/PDF)

```

## Структура науково-дослідницької роботи (орієнтовна)

1. **Вступ** — актуальність (TCCC, ліміт 2 год, втрата маркування), мета, завдання,
   об'єкт і предмет дослідження, методи, новизна, практичне значення.
2. **Розділ 1. Аналіз проблеми та існуючих рішень** — протоколи TCCC, способи фіксації
   часу (маркер, бирки, картки TCCC), відомі електронні рішення, обґрунтування вибору
   технологій (nRF52 vs ESP32, BLE vs LoRa, NFC).
3. **Розділ 2. Розробка апаратної частини** — структурна та принципова схеми,
   енергобюджет (`../power_budget.md`), конструкція кліпси.
4. **Розділ 3. Розробка програмного забезпечення** — архітектура (`../architecture.md`),
   протокол (`../protocol.md`), алгоритми (кінцевий автомат, тріаж, RSSI-пошук).
5. **Розділ 4. Експериментальні дослідження** — `../testing_plan.md` з результатами.
6. **Висновки.**
7. **Список використаних джерел** (ДСТУ 8302:2015).
8. **Додатки** — лістинги ключових модулів, BOM.
