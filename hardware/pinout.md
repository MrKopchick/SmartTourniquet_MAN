# Розпіновка прототипу (Pro Micro / nice!nano nRF52840)

> Єдине джерело правди в коді — `firmware/SmartTourniquet/config.h`. Ця таблиця має з ним збігатися.

| Сигнал | GPIO nRF52 | Підключення | Примітка |
|--------|-----------|-------------|----------|
| REED   | P0.22 | Геркон NO → GND | Wake-up з System OFF (SENSE LOW). TODO: зовнішній pull-up 1–2 МОм |
| BUTTON | P0.24 | Мікрокнопка → GND | Внутрішній pull-up |
| SDA    | P0.17 | OLED SDA | |
| SCL    | P0.20 | OLED SCL | |
| EXT_PWR| P0.13 | VCC OLED | nice!nano: вбудований ключ живлення периферії (HIGH = увімк.) |
| LED    | P0.15 | вбудований | У польовій збірці не використовується (світломаскування) |
| NFC1   | P0.09 | Котушка NFC | **Тільки NFC.** Узгоджувальні конденсатори — див. `schematic/` |
| NFC2   | P0.10 | Котушка NFC | **Тільки NFC.** |
| VDD    | —     | CR2032 (+) / 2×AAA | Паралельно: 100–220 мкФ (низький ESR) + 100 нФ |

## Живлення

```
CR2032 (+) ──┬── C_buf 220 мкФ ──┬── 100 нФ ──┬── VDD (3V3 pin*)
             │                   │            │
CR2032 (–) ──┴───────────────────┴────────────┴── GND
```
\* TODO: перевірити, чи на конкретному клоні подача на пін 3V3 оминає LDO і не живить
його у зворотному напрямку. На nice!nano батарею підключають до B+ (через зарядний IC) —
для CR2032 це неприйнятно (просадка), тому живлення подається напряму на VDD.

## Чому буферний конденсатор

Внутрішній опір CR2032 — 10–30 Ом (росте на холоді та в кінці розряду).
Піки: BLE TX ~5 мА, OLED ~15–20 мА, стирання Flash ~3 мА → просадка до 0.3–0.6 В →
можливий brownout. Конденсатор віддає піковий струм, батарея дозаряджає його повільно.
