## Режим STANDBY (зберігання в аптечці)

| Споживач | Струм |
|----------|-------|
| nRF52840 System OFF (без RAM retention) | ~0.4 мкА |
| Геркон розімкнений → pull-up без струму | 0 |
| Саморозряд CR2032 | ~1 %/рік |

**Висновок:** термін зберігання обмежений саморозрядом батарейки (роки).

## Режим ARMED (турнікет накладено)

| Споживач | Середній струм | Статус |
|----------|----------------|--------|
| System ON idle + RTC (LFXO) | 2–3 мкА | оцінка |
| BLE advertising 1 с, 0 дБм, 22 Б | ~10–15 мкА | оцінка |
| Пробудження циклу кожні 100 мс | ~1–3 мкА | оцінка, TODO: перейти на події |
| Запис у Flash раз на 60 с | ~1 мкА | оцінка |
| **Pull-up 13 кОм через замкнений геркон** | **~230 мкА** | ⚠ TODO: зовнішній 1–2 МОм → ~2 мкА |
| OLED (15–20 мА × 4 с на натискання) | залежить від використання | |

**Без виправлення pull-up:** ~250 мкА → 220 мА·год / 0.25 мА ≈ 880 год (~37 діб).
**З виправленням:** ~20 мкА → ≈ 11 000 год (> 1 року безперервної роботи).

Обидва значення багатократно перекривають 2-годинне вікно TCCC і час евакуації,
але виправлення pull-up — найдешевший спосіб збільшити ресурс у ~10 разів.

## Пікові навантаження (чому потрібен буферний конденсатор)

| Подія | Пік | Тривалість |
|-------|-----|-----------|
| BLE TX (0 дБм, DC/DC) | ~5 мА | ~0.4 мс × 3 канали |
| OLED увімкнено | 15–20 мА | 4 с |
| Стирання сторінки Flash | ~3 мА | ~85 мс |
